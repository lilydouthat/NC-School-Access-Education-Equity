# Data Source Inventory

## Implemented

### Census SAIPE 2024
- District and county school-age poverty measures.
- Used for economic need and school-age population denominators.

### Census TIGERweb
- North Carolina unified school district polygons.
- North Carolina county polygons.
- Land area is used for geographic-access measures.

### NCES EDGE Public School Locations - Current
- 2024-25 public elementary/secondary school point locations.
- Service data updated February 9, 2026; item updated June 2, 2026.
- Used to map actual school sites and calculate school-site scarcity.

## Confirmed for integration

### NC DPI School Report Cards 2024-25
Research files include:
- advanced course enrollment,
- class size,
- chronic absenteeism,
- educator qualifications,
- school improvement funding,
- use of funds,
- per-pupil expenditure,
- arts education indicator.

### NC DPI Statistical Profile 2024-25
Relevant statewide LEA tables include:
- Table 24: per-pupil expenditure ranking,
- Table 32: student transportation on public school buses,
- Table A6: public school personnel summary.

Table 32 includes buses, pupils, annual miles, cost, cost per bus, cost per pupil, and cost per mile.

## Not yet claimed as measured

### Average child commute / bus ride time
Not available from the aggregate transportation fields identified so far. Do not calculate individual commute distance from systemwide bus miles.

### Athletics / extracurricular opportunity
NC School Report Cards explicitly note that sports and other extracurricular dimensions are not fully reflected in the report card. A future athletics layer needs a distinct defensible data source rather than a proxy presented as fact.
